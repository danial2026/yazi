# yazi

- Fast (written in Rust)
- Image previews in Kitty
- PDF preview
- Video thumbnails (with ffmpeg)
- Archive browsing
- Syntax highlighting
- Vim keybindings
- Bookmarks (favorites)
- Tabs
- Plugin system
- Git status
- Works on macOS and Linux

## install

```sh
# macOS
brew install yazi ffmpeg sevenzip jq poppler fd ripgrep fzf zoxide

# Arch
sudo pacman -S yazi ffmpeg p7zip jq poppler fd ripgrep fzf zoxide
```
